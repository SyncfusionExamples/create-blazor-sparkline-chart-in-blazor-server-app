# Blazor Sparkline Chart - Getting Started

This sample shows how to use the [Blazor Sparkline component](https://www.syncfusion.com/blazor-components/blazor-sparkline) in a Blazor Server app. It demonstrates a compact sparkline with labels, markers, and tooltips, then combines the chart with a grid to present tabular and visual data together.

## Overview

Sparkline charts are designed for high-density dashboards where a full chart would take too much space. This sample focuses on a practical setup that includes:

- a category-based sparkline bound to monthly climate data
- a grid with an embedded sparkline in a template column
- Fluent 2 theme styling
- interactive server-side Blazor rendering

## Features

- Compact sparkline rendering with labels, markers, and tooltips.
- Embedded sparkline inside a data grid template column.
- Server-side Blazor integration with Fluent 2 styling.
- Lightweight, production-ready sample for quick integration.

## Prerequisites

* [.NET SDK 10.0](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) or later
* [Visual Studio 2022](https://visualstudio.microsoft.com/vs/) or later
* [Visual Studio Code](https://code.visualstudio.com/)

## Getting Started

### Clone the repository

```bash
git clone https://github.com/SyncfusionExamples/create-blazor-sparkline-chart-in-blazor-server-app.git
cd create-blazor-sparkline-chart-in-blazor-server-app
```

### Run with Visual Studio

1. Open the solution file using Visual Studio 2022 or later.
2. Restore the NuGet packages by rebuilding the solution.
3. Build the project to ensure there are no compilation errors.
4. Run the project.

### Run with .NET CLI

```bash
# Restore dependencies
dotnet restore

# Run the project
dotnet run
```
